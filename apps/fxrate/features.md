# FxRate 기능 상세

## 환율 탭 (feature:rates)

- 기준 통화 환산, 목록 전체 금액 환산(금액 입력 하나로 계산기를 대신), 즐겨찾기 순서 편집, 상세 시트를 담는다
- 화면 상태 매핑을 ViewModel 에서 떼어 순수 함수로 두고, 환산·변동량·정렬은 위젯과 같은 `RateBoard` 를 쓴다. 이 모듈에 다시 구현하지 않는다
- 헤더 금액 입력과 시트 금액 입력은 한 상태 필드로 합치지 않는다. 헤더는 목록 환산용(나눗셈), 시트는 해당 통화 환산용(곱셈)이라 방향이 반대다
- 변동량도 환산해 보여주고, 금액 환산 모드의 행에도 단위 환율 줄을 남긴다
- 즐겨찾기 순서 편집은 위·아래 버튼이다(드래그 아님). 이동은 검색으로 거르지 않은 즐겨찾기 코드 목록에서 계산한다
- 알림 이동은 `feature:alerts` 를 의존하지 않고 `OpenAlertFor` 효과로 올려 앱 모듈이 알림 탭으로 보낸다

## 알림 탭 (feature:alerts)

- 임계값 규칙의 목록·추가·수정·삭제·켜고 끄기. 규칙 상한은 20개
- 평가와 발송은 서버 몫이고 앱은 규칙을 만들고 보여주기만 한다. 판정 명세는 공용 `threshold-alert` 모듈에 있고 이 모듈은 의존하지 않는다(규칙이 두 곳에 생기면 서버와 맞출 기준이 없다)
- 규칙 흐름과 환율 캐시 흐름을 합쳐 순수 함수 매퍼로 상태를 만든다. 각 줄에는 현재 값과 임계값까지의 남은 거리 또는 "조건 충족"이 나온다
- 환율이 갱신될 때마다 열려 있던 편집 시트와 삭제 확인이 닫히지 않도록, 방출마다 직전 편집 상태를 되살려 넣는다
- 쓰기 호출은 취소를 실패로 삼키지 않는 래퍼로 감싸 실패를 스낵바 효과로 돌린다
- 저장할 때 `armed` 를 초기화한다. 이전 조건에서 발동해 내려간 채로 조건만 바꾸면 새 조건이 처음부터 발동하지 않기 때문이다
- 삭제는 복구할 수 없어 요청·확인·실행 3단계를 거친다. 편집 시트는 `skipPartiallyExpanded` 로 열어 저장 버튼이 잘리지 않게 한다
- 서버 반영은 아직 배선되지 않아 규칙은 로컬에만 쌓이고 "반영 대기" 칩이 붙는다

## 설정 탭 (feature:settings)

- 기준 통화 변경, 출처(탭하면 출처 링크 열기)·오픈소스 라이선스·문의·앱 버전 행
- 선택 가능한 통화는 캐시 스냅샷의 통화 코드와 기준 통화로만 채운다. 하드코딩 카탈로그는 캐시가 비었을 때의 대체 목록이다
- 동작하지 않는 항목은 만들지 않는다. 푸시가 배선되기 전까지 알림 스위치를 두지 않는다
- 화면 뼈대와 버전·정보 섹션은 공용 `SettingsScaffold` 에 위임한다

## 스플래시 (feature:splash)

- 로고 화면이 아니라 강제 업데이트 게이트다. 흐름은 공용 splash-base 가 갖고 이 앱은 추상 멤버 둘만 채운다
- 버전 확인 실패는 통과시키는 정책(`PROCEED`)이다. 조회 앱이라 원격 설정을 못 읽었다는 이유로 막으면 환율을 보려던 사용자가 아무것도 못 한다. 막을 대상은 구버전이지 확인 불가가 아니다. 반대로 지원 종료 버전은 통과시키지 않고, 선택지는 스토어 이동과 앱 종료뿐이다
- 확인은 제목·부제 페이드가 끝난 뒤 화면이 시작한다. base 의 스코프가 즉시 실행이라 생성 중에 시작하면 하위 클래스 초기화 전에 정책 함수가 불릴 수 있다

## 홈 화면 위젯 (core:widget)

- Glance 위젯. 즐겨찾기 순서대로 최대 5줄(런처 칸이 좁다), 즐겨찾기가 비면 기본 4개 통화(USD·JPY·EUR·CNY)를 보여준다. 헤더에는 기준 통화와 시세 경과 시간("방금"·"N분 전" 등)이 나온다
- 위젯에서 네트워크를 부르지 않고 로컬 캐시·설정·즐겨찾기만 읽는다. 어디를 눌러도 앱이 열린다
- 리시버에 상태를 두지 않고 `provideGlance` 안에서 EntryPoint 로 의존성을 꺼낸다. 컴포지션 안에서는 흐름을 구독하지 않아 값은 다음 갱신 실행 때만 바뀐다
- 앱이 `WidgetSync` 로 갱신을 밀어 준다(앱 시작 시 한 번 시작)
- 색은 화면과 같은 `TrendPalette` 상수를 Glance 타입으로 감싸 쓴다

## 개발용 목 데이터 (debug 전용)

USD 기준 20통화의 현재값·직전값 쌍과 기본 즐겨찾기(USD·JPY·EUR)를 실제 저장 경로로 두 번 저장해 주입한다. 캐시에 값이 이미 있으면 아무것도 하지 않는다. release 소스셋에는 코드가 없다.
