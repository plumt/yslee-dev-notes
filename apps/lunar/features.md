# Lunar - 기능별 상세

각 항목은 feature 모듈 하나에 대응한다. 모든 화면은 `XxxScreen` 하나만 공개하고 `XxxContent` 는 `private` 로 둔다.

## 홈 (`feature:home`, route `home`)

오늘의 달 위상 대시보드이며 시작 탭이다.

- 표시: 달 이미지(Canvas), 위상 이름·설명, 조도(%), 음력 N일, 오늘의 특별 이벤트 이름, 보름달/신월까지 남은 일수, 블루문 임박 여부
- 다가오는 위상 타임라인: 이번 달과 다음 두 달의 이벤트 중 현재 이후 4개. 이번 달만 보면 월말에 목록이 비기 때문이다
- 현재 위치(없으면 서울) 기준 월출·월몰과 기상청 하늘상태·강수로 판단한 "달 보기" 정보
- 미읽음 알림 수를 알림함 진입 버튼에 표시
- 기준 시각은 `TimeProvider.dayTicks(KST)` 로 지금과 KST 자정마다 갱신해 자정을 넘겨도 낡은 상태가 남지 않는다
- 블루문 판정은 그 달 보름달을 모두 계산해 두 번 이상이면 마지막 것만 블루문으로 본다

## 달력 (`feature:calendar`, route `calendar`)

- 월 이동(이전/다음)과 격자/목록 두 탭. 탭 전환은 재적재 없이 같은 목록을 다른 모양으로 그린다
- 격자는 7열, 일요일 빨강·토요일 강조색, 오늘 강조. 칸 하단 영역 높이를 고정해 레이블 유무와 무관하게 달 크기가 같다
- 삭망 날짜에 이벤트 이름과 시각(HH:mm), 블루문이면 "블루문" 표시
- 본문 분기 순서는 적재 중 -> 실패 -> 목록 탭 -> 격자. 머리글과 탭은 항상 남겨 다른 달로 넘어갈 수 있다

## 달 탐구 (`feature:explore`, route `placeholder`, 딥링크 host `explore`)

- 그 해의 블루문·슈퍼문·미니문을 시간순으로 나열. 지난 항목도 흐리게 두고 목록에서 빼지 않는다(그 해 전체를 보여 주는 화면이라서다)
- 거리는 만 단위 km 로 표시(예: 약 35.7만 km). 네트워크 의존을 들이지 않고 전부 로컬 계산이다
- route 값은 과거 placeholder 이름이 남아 있고 딥링크 host 만 explore 다

## 이달의 하늘 (`feature:sky`, route `sky`)

- 한국천문연구원(KASI) 월별 해설 글과 천문현상 일정 카드(종류 배지, 날짜, 시각, 원문)
- 일정을 누르면 위키백과 요약을 펼친다. 후보 문서 제목을 앞에서부터 물어 404 면 다음 후보로 넘어가고, 한 번에 하나만 펼친다
- 오늘 일정에 "오늘" 표시, 지난 일정은 흐리게. 식·유성우 배지만 강조색
- 달 이동은 오늘(KST)이 든 달에서 시작하며, 앞 요청을 취소하고 같은 달일 때만 결과를 반영해 늦게 온 응답이 덮어쓰지 않게 한다
- 위키백과 출처·라이선스·원문 링크와 KASI 출처 표기를 지우지 않는다

## 설정 (`feature:settings`, route `settings`)

- 달 알림 토글 2종(달의 위상 / 특별한 달), 앱 버전, 개인정보 처리방침, 문의하기, 오픈소스 라이선스
- 화면 뼈대는 공용 `SettingsScaffold` 가 그리고 이 모듈은 알림 섹션만 넘긴다
- 켜기 흐름: 알림 권한 확인 -> 필요 시 시스템 요청 -> 거부면 안내 다이얼로그, 영구 거부면 앱 설정 이동 다이얼로그 -> Firebase 준비 확인 후 토픽 구독 성공 시에만 ON 저장
- 토픽 이름·문의 메일 등 설정값은 NDK `NativeConfig` 를 직접 읽지 않고 `FcmTopics`·`ContactInfo` 래퍼를 거친다

## 알림 (`feature:notification`)

달 이벤트 FCM 메시지를 로컬 알림으로 바꾸는 핸들러로, 의존에 추가하면 라우터에 자가등록된다.

| eventType | 갈래 | 제목 |
|---|---|---|
| full_moon | 달의 위상 | 오늘은 보름달이에요 |
| new_moon | 달의 위상 | 오늘은 새달이에요 |
| supermoon | 특별한 달 | 오늘은 더 크고 밝은 달이에요 |
| minimoon | 특별한 달 | 오늘은 평소보다 작은 달이에요 |
| blue_moon | 특별한 달 | 오늘은 한 달에 두 번째 보름달이에요 |

- 본문은 페이로드 description 이 있으면 그대로 쓰고 없을 때만 종류별 기본 문구로 떨어진다. 그래서 문구는 서버 배포만으로 바뀐다
- 알림 ID 는 고정이라 새 알림이 이전 달 알림 자리를 덮고, `BigTextStyle` 로 본문을 펼친다
- 모르는 eventType 은 토글 판정에서 항상 false 라 표시하지 않는다(모르는 이벤트를 켜진 것으로 보는 쪽이 더 나쁘다)
- `handle` 안의 예외는 로그로 끝내고 밖으로 던지지 않는다

## 스플래시 (`feature:splash`)

- 공용 `SplashScaffold` 로 보름달 로고 페이드인을 그리고, 끝나면 버전 확인을 시작한다
- 조회 실패 정책은 `PROCEED` 라 네트워크가 없어도 홈으로 진행한다. 강제 업데이트가 필요하면 공용 업데이트 다이얼로그가 막는다
- 홈 route 를 모르고 `onNavigateToHome` 콜백으로만 이동한다. 홈으로 넘길 때 스플래시를 백스택에서 걷어낸다

## 공통 (`core:common`)

- 달 위상 그림(`MoonPhaseImage`), 위상 이름 구간표, 날짜·거리 포맷(`LunarPhaseFormat`), 표시 모델(`MoonPhase`)
- 알림 설정 `MoonNotificationSettings`(DataStore 파일 `moon_notification_prefs`). 저장 키와 파일 이름은 바꾸면 기존 설정이 사라진다
- 테마 `LunarPhaseTheme`: 앱 본체는 Midnight 팔레트 + `DarkMoonColors`, 프리뷰용 라이트 팔레트도 있다

## 위상 이름 구간

| 이름 | 위상 p 구간 |
|---|---|
| 신월 | p <= 0.01 또는 p >= 0.99 |
| 초승달 | 0.01 ~ 0.24 |
| 상현달 | 0.24 ~ 0.26 |
| 상현 볼록달 | 0.26 ~ 0.48 |
| 보름달 | 0.48 ~ 0.52 |
| 하현 볼록달 | 0.52 ~ 0.74 |
| 하현달 | 0.74 ~ 0.76 |
| 그믐달 | 0.76 ~ 0.99 |

반달 이름 구간(폭 0.02)은 그림의 반원 구간(폭 0.04)보다 좁다.
