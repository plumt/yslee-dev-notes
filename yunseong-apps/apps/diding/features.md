# Diding - 기능별 상세

## 오늘 (`feature:home`, route `home`)

시작 화면이다. 오늘 해당하는 할 일 목록을 보여 주고 완료를 토글한다.

- 오늘 목록 조립은 도메인 `GetTodayTodosUseCase` 가 한다. 보관되지 않은 할 일과 그날 완료 id 를 합쳐 반복 판정으로 거른다. 목록 순서는 저장소가 준 생성순 그대로다
- 진행 수·달성률은 `HomeUiState` 의 파생값이며 화면에서 다시 세지 않는다
- 목록이 비면 진행 카드 없이 빈 상태 화면을 남은 영역 전체에 띄운다
- 완료 토글은 `ToggleCompletionUseCase` 가 누른 시점의 날짜 키로 완료 기록을 넣거나 지운다
- 자정이 지나면 `dayTicks()` 가 새 기준 시각을 내 목록이 새 날짜로 바뀐다

## 관리 (`feature:management`)

반복 할 일을 추가·수정·보관한다.

| 요소 | 내용 |
|---|---|
| 목록 | 제목과 반복 라벨(매일 / 요일 나열 / 매월 N일 / 반복 없음)을 카드로 표시 |
| 시트 | 제목, 반복 칩(매일·매주·매월), 요일 선택기, 일자 슬라이더(1~31), 알림 토글과 시각 선택 |
| 저장 조건 | 제목이 공백이 아니고 반복 규칙이 온전할 때만 버튼이 켜짐(매주는 요일 1개 이상, 매월은 일자 1~31) |
| 저장 후 | 시트를 닫고 입력을 기본값으로 되돌린 다음 알람 전체를 재예약 |
| 알림 기본값 | 꺼짐, 9시 0분. 껐다 켜도 고른 시각이 남는다 |

- 보관은 물리 삭제가 아니라 `isArchived` 로 처리한다
- 저장 중에는 버튼을 꺼 재진입을 막는다
- 반복 없음은 새로 고를 수 없지만, 기존 항목을 편집할 때 유형을 건드리지 않으면 그대로 저장된다

## 캘린더 (`feature:calendar`, route `calendar`)

- 월별 달력에서 날짜마다 할 일 수행률을 색으로 그린다
- 월 범위, 칸 배치, 날짜별 달성률은 도메인 `MonthAchievement` 로만 계산한다. 화면에서 반복 판정과 집계를 다시 쓰지 않는다
- 수행률의 분모는 그날 해당하는 할 일이다. 홈 목록과 같은 판정 함수를 쓴다
- 오늘은 `dayTicks()` 로 자정마다 다시 읽는다

## 설정 (`feature:setting`, route `setting`)

- 알림 마스터 스위치, 앱 버전, 문의(메일), 오픈소스 라이선스 행. 화면 뼈대는 공용 `SettingsScaffold`
- 알림 켜기: 권한 확인과 요청 -> `Granted` 일 때만 설정 값을 올리고 알람 전체 예약. 거부면 토글을 내림. 영구 거부면 앱 설정 이동 안내
- 알림 끄기: 설정 값을 내리고 알람 전체 취소
- 문의 메일 주소는 `@SupportEmail` 주입으로만 받는다(`NativeConfig` 는 앱마다 생성되어 이 모듈에서 보이지 않는다)

## 알람 (`core:alarm`)

| 구성 | 역할 |
|---|---|
| `TodoAlarmSchedulerImpl` | `TodoAlarmScheduler` 포트의 전체 재예약·전체 취소 구현. 정확 알람 호환 계층으로 one-shot 알람 등록 |
| `TodoAlarmReceiver` | 발화 시 재검증 후 알림 발송, 다음 알람 재예약 |
| 재예약 경로 | 재부팅과 앱 교체 뒤 알람을 복구한다. 공용 재예약 리시버(`:shared:core:fundamental:alarm`)가 `TodoAlarmReschedulerModule` 기여를 통해 `scheduleAll` 을 부른다 |

알림은 제목 "Diding", 본문 할 일 제목이며 같은 할 일의 다음 알림은 같은 id 라 앞 알림을 덮는다. 탭하면 앱 런처 화면이 열린다(앱 진입 정보 포트 사용).

## 딥링크

| host | 이동 |
|---|---|
| `home` | 오늘 |
| `management` | 관리 |
| `calendar` | 캘린더 |
| `setting` | 설정 |

예: `yunseong-diding://calendar`. 경로와 쿼리가 붙은 링크는 거부된다.

## 테마

밝은 종이 톤 고정 테마다. accent 는 그린, 브랜드 값은 한 파일에 모여 있고 시스템 다크 설정은 읽지 않는다. 런처 아이콘은 초록 배경에 흰 십자 적응형 아이콘이다.

## 테스트

- 알람 다음 발화 시각 계산은 고정 시각(`TimeProvider`)으로 `core:alarm` 단위 테스트가 검증한다
- E2E: 공용 Appium 러너 위에 앱의 `appiumTest/` 설정과 스모크 시나리오(dev 플레이버)가 있다. 바텀바 testTag(`diding_bottom_bar`)와 `testTagsAsResourceId` 로 셀렉터를 잡는다
